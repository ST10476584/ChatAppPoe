# Chat Application PoE

## 📌 Project Description
This is a Java console-based chat application created for a Portfolio of Evidence (PoE).  
It includes user registration, login functionality, and input validation.

## 📌 Features
- Username validation (underscore + max 5 characters)
- Password complexity validation
- South African phone number validation (+27 format)
- User registration system
- Login authentication system
- JUnit unit testing

## 📌 Technologies Used
- Java
- NetBeans
- JUnit 4
- Git & GitHub

## 📌 How to Run
1. Open project in NetBeans
2. Run `Main.java`
3. Follow console prompts for registration and login

## 📌 Testing
Run `LoginTest.java` to execute unit tests.
